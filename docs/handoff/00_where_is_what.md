## กฎก่อนทำงาน
1. อ่านไฟล์นี้ + รัน `git log --since=<3 วันก่อน> --pretty="%h %ad %s"` ดูว่าฝั่งโค้ดทำอะไรไปแล้ว
2. จะทำม็อกบนหน้าจอที่มีอยู่แล้ว → ใช้ **ภาพจากเกมจริง** เป็นพื้น (เว็บ https://haruby-dev.github.io/help-tower-game/ เปิดผ่านเบราว์เซอร์ในแอป Claude; คอนเทนเนอร์เข้าเว็บนี้ไม่ได้) ห้ามใช้ม็อกเก่าหรือภาพหน้าจอเก่าโดยไม่เช็ก
3. ก่อนเขียน prompt → เทียบกับแถว "ตัดสินแล้ว" ในไฟล์นี้ทุกข้อ ห้ามเขียนรายการ (เช่น รายชื่อแอป) จากความจำ
4. เธออนุมัติ / เขียน prompt / เห็น commit → แก้แถวในไฟล์นี้ทันที
