1. อ่านไฟล์นี้ + **`00_rules.md` + `04_us.md`** (วิธีทำงานกับเธอ ห้ามข้าม) + ท้าย `01_status.md` + ไฟล์ next ล่าสุด + รัน `git log --since=<3 วันก่อน> --pretty="%h %ad %s"` ดูว่าฝั่งโค้ดทำอะไรไปแล้ว
