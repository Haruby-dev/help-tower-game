## B. Tricks learned this chat
- Delivering binaries to her PC: zip into `/mnt/user-data/outputs/<new name>.zip` → `device_commit_files` → unzip with python on the device → check the pixel hash. Large base64 through device_bash got corrupted once.
- Getting a local image into PixelLab: `pixelart_workbench edit data:image/png;base64,... --changes [no-op patch]` (PNG only, keep base64 < ~8 KB) → the result has a `pixel-tools/<id>/image.png` URL usable as `reference_image_url`. `inspect` results have no download URL.
- Workbench `edit` layer name is `"image"`; adding pixels on transparent spots needs `brush`, not `patch_pixels`.
- Recolour masks: protect outline `#682215/#703224`, blush `#fd8c80`, and plush/leaf greens before mapping colours.
