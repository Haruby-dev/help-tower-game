## 3. ⏳ ยังค้าง (ทำต่อได้ ถามเธอก่อน)
1. **ตำแหน่งครกในบ้าน** — เธอสั่ง "อย่าเพิ่งจด" · ข้อเสนอที่ค้าง: ระหว่างยังไม่มีห้องในบ้าน กดประตูบ้าน → เมนู "นอน / ตำครก" (ขึ้นหลังเกต 3) · จริง ๆ = มุมครัวในบ้าน ตอนออกแบบห้องในบ้าน
2. **อาหารปริศนาตอนเกจสุข ≤30** (GDD ตารางเกจ 15%) — ไม่เคยมีในโค้ด สั่ง OPEN ไว้ ต้องถามเธอว่าเก็บไหม
3. **ภาพที่ยังขาด** (โค้ดใส่กล่องสีแทน): โต๊ะช่าง · ต้นกล้วย · ไม้ไผ่ · แก้วไม้ไผ่ · ไอคอนครีม / น้ำฟองซ่า / เศษเยลลี่สไลม์ · ไอคอนใบโหระพา + วิปครีมในกระเป๋า · ฟอง 🤢 😵 · (เศษม้วนสูตรใช้ภาพม้วนเดิม) — บอกราคาเครดิตก่อนทุกครั้ง หรือวาดมือ 0 cr
4. **ค่าเริ่มต้นที่ผมใส่ในสเปก (บอกเธอแล้ว ยังไม่ค้าน):** แก้วไม้ไผ่ = ไม้ไผ่ 1 · ถาดตาก = ไม้ไผ่ 3 + ฟาง 2 · ลอบ = ไม้ไผ่ 2 + เชือก 2 · ลูกชิ้นใส่ได้ ซุปมะเขือเทศ แกงจืด สตูว์ ข้าวต้มปลา · โต๊ะใหญ่มอนกินได้แบบถาดหอคอย · ชื่อเสียงโชว์หัวหน้าสูตรในร้าน · ท่าทำขนม/น้ำตามภาชนะ · กุ้ง 70 ปู 30 · ผงนัว/พริกป่น/กุ้งแห้งป่น
5. **ระบบอื่นที่ผ่านแล้วแต่ยังไม่ส่งโค้ด** (ไม่อยู่ใน prompt อาหาร): หน้าต่างสถานะ C + สกิล + ภารกิจรายวัน/ดาวน้ำตาล · ดาว 5 สี (ตัวเลข/ปุ๋ยยังเปิด) · อากาศที่ผักชอบ + ไอคอนอากาศในร้าน · ถังหมักปุ๋ย · ห้องในบ้าน (ยังไม่ออกแบบ) · ร้านอาหาร + เพื่อนมอนสเตอร์ (ยังไม่มีในโค้ด)
6. ไม้ไผ่มาจากระบบเกต M8 ที่ยังไม่ทำ → ของที่ใช้ไม้ไผ่จะเล่นจริงได้หลัง M8
