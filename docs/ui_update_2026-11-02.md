# UI update — 2026-11-02 (from the planning side). This REPLACES the look parts of B11 and B12's portrait frame.

The user reviewed real phone screenshots. The current UI looked "cut and pasted": smooth, vector-like and high resolution on top of a pixel game. Fix it with the rules and art below. Mockups are in `docs/level/2026-11-02/` (ui17, ui21, ui22, ui23, ui24).

## Global UI rules

1. **Draw all UI in game pixels at the same integer zoom as the world.**
   - No smooth vector shapes, no CSS rounded boxes, no blur or glass.
   - Use the PNGs below with nearest-neighbour scaling only.
2. **Font: use Mali everywhere.**
   - The phone cover currently falls back to a serif font, so Mali is not loading there. Fix the font loading or the font-family on that element.
   - Draw text in the dark plum `#5C304C` or white. No system fonts.
3. **Everything is opaque.** The user rejected translucent or glass UI.
4. **Palette:**

   | Role | Colour |
   |---|---|
   | Outline | `#5C304C` |
   | Light pink | `#FFDCE8` |
   | Pink | `#F8B4CC` |
   | Cream | `#FFF6F0` |
